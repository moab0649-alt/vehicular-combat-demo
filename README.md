# Vehicular Combat Demo

Static browser scaffold for a mobile-first vehicular combat game demo.

## Run

1. Open `/home/runner/work/vehicular-combat-demo/vehicular-combat-demo/index.html` directly in a browser.
2. You can also drag `index.html` into a browser window.
3. No server or build step is required.

## Controls

- **Menu:** tap **Open Garage**
- **Garage:** tap **Enter Arena** or **Back**
- **Arena:** tap **Win Match**, **Lose Match**, or **Garage**
- **Results:** tap **Play Again** or **Main Menu**

The app is designed to work from `file://` with touch-friendly controls and no external requests.
